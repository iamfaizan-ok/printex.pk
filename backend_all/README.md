# Backend Service (Phase 2)

This directory is designated for the upcoming Django REST Framework (DRF) backend service.

### Scope:
- REST API for order creation (`/api/v1/orders/create/`) and tracking (`/api/v1/orders/:orderId/`).
- Multipart file upload API (`/api/v1/documents/upload/`).
- Server-side dynamic pricing calculation (`/api/v1/pricing/calculate/`).
- Payment gateway integration (Stripe, JazzCash, EasyPaisa).
