# Backend Service (Phase 2)

This directory is designated for the upcoming Django REST Framework (DRF) backend service.

### Scope:
- REST API for order creation (`/api/v1/orders/`) and tracking.
- Secure server-side PDF validation, virus scanning, and storage.
- Dynamic pricing engine based on print shop rates, paper stock, and duplex options.
- Payment gateway integration (Stripe, JazzCash, EasyPaisa).
